# Contributing

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

Please read and follow our [Code of Conduct](CODE_OF_CONDUCT.md).

## How to Contribute

1. Fork this repository and clone your fork.
2. Create a branch for your change: `git checkout -b my-change`.
3. Make your changes and test them by running `./simple-interest.sh`.
4. Commit with a clear message and push the branch to your fork.
5. Open a pull request describing what you changed and why.

## How to Report Bugs

1. Search the existing issues to check the bug hasn't already been reported.
2. Open a new issue using the **Bug report** template.
3. Include the inputs you entered, the output you expected, the output you got,
   and your operating system and Bash version.
